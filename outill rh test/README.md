# Outil RH - Gestion des Absences

Version test gratuite en HTML, CSS et JavaScript.

## Fonctionnalités

- Ajouter une absence
- Type d'absence
- Date début / date fin
- Calcul automatique des jours
- Statut : En attente, Validée, Refusée
- Historique des absences
- Recherche
- Export CSV
- Données sauvegardées dans le navigateur

## Mise en ligne gratuite avec GitHub Pages

1. Créer un dépôt GitHub.
2. Ajouter ces fichiers :
   - index.html
   - style.css
   - script.js
3. Aller dans Settings > Pages.
4. Choisir Branch: main.
5. Cliquer sur Save.

Attention : cette version est pour test. Les données sont stockées seulement dans le navigateur.
